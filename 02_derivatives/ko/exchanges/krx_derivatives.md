### 주요 연혁 (Key Historical Milestones)

- **1996년:** KOSPI200선물 상장 (5월 3일) — 한국 최초의 장내 파생상품
- **1997년:** KOSPI200옵션 상장 (7월 7일) — 이후 거래량 기준 세계 최다 거래 단일 계약으로 부상
- **1999년:** 부산에 한국선물거래소(KOFEX) 별도 설립
- **2001년:** USD선물 및 주식옵션 상장
- **2002년:** CD금리선물, 국채3년선물(KTB 3Y) 상장
- **2004년:** 국채10년선물(KTB 10Y) 상장
- **2005년:** 한국증권거래소(KSE), KOSDAQ위원회, 한국선물거래소(KOFEX) 합병으로 KRX 출범 (1월 27일)
- **2008년:** 돈육선물, 금선물 상장
- **2009년:** KRX 세계 최대 거래소 등극 (31억 계약); 섹터지수선물/옵션 상장
- **2011년:** 역대 최고 거래량 39억 3천만 계약 달성; KOSPI200옵션 단독으로 약 36억 7천만 계약 기록
- **2012년:** KOSPI200옵션 승수 10만 원에서 50만 원으로 5배 인상 (6월); 이에 따라 연간 거래량 53.3% 급감
- **2014년:** EXTURE+ 거래시스템 출범 (기존 EXTURE 시스템 대체)
- **2015년:** 미니선물/미니옵션 상장; V-KOSPI200선물 상장
- **2017년:** 위클리옵션 (주간 KOSPI200옵션) 상장
- **2019년:** KOSDAQ150선물/옵션 상장
- **2022년:** 섹터지수옵션 상품군 확대
- **2025년:** 독립 야간거래 세션 출범 (6월 9일, Eurex 연계 시간외거래 세션 대체); KRX 기술 태국증권거래소(Thai Stock Exchange) 수출 (2025년 4월 계약 체결)
- **2026년:** KOSPI200옵션 행사가격 확대 (4월 27일부터 48개 추가 행사가격 도입); 신규 주식선물/옵션 상장; TIGER반도체 ETF선물 상장

### 2.5 유동성공급자 프로그램 (Market Maker / Liquidity Provider Programs)

KRX는 파생상품 전 상품에 걸쳐 유동성공급자(LP) 프로그램을 운영한다:

**프로그램 구조:**
- KRX가 특정 상품에 대한 유동성공급자를 지정하며, 지정된 유동성공급자는 양방향 호가를 지속적으로 제공해야 한다
- 유동성공급자는 수수료 환급 및 거래량 기반 인센티브를 수령한다
- KRX가 정기적으로 성과를 평가하며, 미달 시 지정이 취소될 수 있다

**운영 중인 프로그램:**
- KOSPI200옵션 (위클리옵션 및 미니옵션 포함)
- 섹터지수옵션
- USD옵션
- 주식옵션 및 주식선물
- 미니선물/미니옵션 상품군
- KOSDAQ150옵션

## 3. 매매거래 체결 방식 (Trading Mechanism)

### 3.1 단일가매매 유형 (Auction Types)

**개시단일가 (Opening Single-Price Auction):**
- 정규거래 및 야간거래 세션 초반에 적용
- 체결 수량이 최대가 되는 가격에서 누적 주문을 일괄 체결
- 시세 조작 방지를 위한 임의종료시간 적용

**종가단일가 (Closing Single-Price Auction):**
- 정규거래 및 야간거래 세션 마지막 10분 적용 (정규거래: 15:35–15:45 KST)
- 단일가매매 알고리즘으로 결제가격 결정
- 임의종료시간 적용

**변동성 완화장치 (Intraday Volatility Interruption):**
- 동적VI 또는 정적VI 발동 조건 충족 시 일시적 단일가매매로 전환
- 2분간 냉각 후 단일가매매 실시

### 3.2 접속매매 (Continuous Trading)

- **가격우선·시간우선 원칙:** 표준 FIFO 체결 방식 — 최우선 가격 주문이 먼저 체결되며, 동일 가격 내에서는 접수 시각이 빠른 주문이 우선 체결
- **주문주도형 시장:** 스페셜리스트 또는 딜러 제도 없이, 유동성은 일반 투자자 및 유동성공급자 주문으로 구성
- EXTURE+ 플랫폼을 통한 완전 전자 체결

### 3.3 가격 발견 (Price Discovery)

- **시가:** 세션 개시 시 단일가매매 알고리즘으로 결정
- **결제가격:** 결제 구간 내 최종 체결가 (일부 상품의 경우 최종결제에 VWAP 방식 적용)
- **KOSPI200선물 최종결제가격:** 최종거래일 마지막 30분간 구성 종목 시가의 가중평균값으로 산출하며, 시세 조작 방지 목적의 계산 방식 적용
- **내재가격 산정:** 미지원 — KRX는 직접 오더북 매칭 방식만 사용 (CME Globex의 내재 스프레드 기능과 상이)

## 4. 주문 유형 (Order Types)

업무규정 기준:

| 주문 유형 | 한국어 명칭 | 설명 |
|----------|-------------|------|
| **지정가주문** | 지정가 | 가격을 지정하여 지정가 또는 유리한 가격에 체결 |
| **시장가주문** | 시장가 | 접수 즉시 최우선 가격에 체결 |
| **최유리지정가주문** | 최유리지정가 | 접수 시점의 최우선 상대방 호가로 지정가주문으로 전환되어 체결 |
| **조건부지정가주문** | 조건부지정가 | 접속매매 중에는 지정가로 작동하며, 종가단일가 시 시장가로 전환 |
| **IOC주문** | 즉시체결·잔량취소 | 즉시 체결 가능한 수량만 체결하고 잔량은 취소 |
| **FOK주문** | 전량체결·전량취소 | 전량 체결이 불가능한 경우 주문 전체 취소 |
| **조건부주문** | 조건부주문 | 기준가격이 지정 수준에 도달할 때 발동하는 스톱 주문 |
| **스프레드주문** | 스프레드주문 | 서로 다른 결제월 계약을 지정 가격 차이로 동시에 매수/매도 |

**유효기간:** 정규거래 세션은 당일(DAY)만 적용; 야간거래 주문은 별도로 관리되며 정규거래로 이월되지 않는다.

## 5. 거래 시스템 (Trading System / Technology)

| 항목 | 내용 |
|------|------|
| 시스템명 | EXTURE+ (EXTURE Plus) |
| 가동 연도 | 2014년 |
| 개발사 | KOSCOM (KRX 기술 자회사) |
| 아키텍처 | 메모리 기반 오더북, x86 Linux 서버상 계층형(tiered) 아키텍처 |
| 지연시간 | 평균 약 30–50마이크로초 (일부 자료에서 약 70마이크로초로 기재) [미확인] |
| 처리 용량 | 초당 100,000건 이상 (TPS) |
| 성능 개선 | 기존 EXTURE 대비 약 285배 빠름 |
| 프로토콜 | FIX/FAST (시장 연결) |
| 데이터 인프라 | Solace PubSub+ (고속 데이터 전송) |
| 적용 범위 | 통합 플랫폼: 주식, 채권, 선물, 옵션, ETF, 워런트, 상품 |
| 주요 기능 | 오픈소스 아키텍처, 무중단 장애복구(zero-data-loss failover), 리스크 필터링 적용 DMA, 다단계 서킷브레이커, 알고리즘/HFT 지원 |
| 코로케이션 | 부산 데이터센터 내 KRX 코로케이션 시설 운영 |
| 기술 수출 | KRX는 EXTURE+ 기술을 해외 거래소에 수출 중 (태국증권거래소와 2025년 4월 계약 체결) |

**이전 시스템:**
- **EXTURE** (2009년): KOSDAQ 및 파생상품 레거시 시스템을 통합 대체
- **2009년 이전:** 주식(KSE), KOSDAQ, KOFEX 파생상품별 별도 거래시스템 운영

## 8. 리스크 관리 및 서킷브레이커 (Risk Controls & Circuit Breakers)

업무규정 및 시행세칙 기준:

### 8.1 정적 가격 제한폭 (일별, Static Price Limits)

| 상품 | 가격 제한폭 |
|------|------------|
| KOSPI200선물 | 전일 결제가격 대비 ±10% |
| 주식선물 | ±30% (기초자산인 주식의 일일 제한폭과 동일) |
| 국채선물 | ±1.5% (3년물), ±2.1% (10년물) [미확인 — 규정 표 기반] |
| USD선물 | 전일 결제가격 대비 지정 비율 기준 |

### 8.2 동적VI (Dynamic Volatility Interruption)

- 체결가격이 기준가격 대비 ±3% 이상 이탈 시 발동 (KOSPI200선물 기준)
- 2분간 냉각 후 단일가매매 실시
- 선물 및 옵션 계약 모두에 적용
- VI 발동 후 기준가격 갱신

### 8.3 정적VI (Static Volatility Interruption)

- 가격이 전일 결제가격 대비 지정 비율을 초과하여 이탈할 경우 발동
- 거래 중단 후 단일가매매 실시
- 발동 기준은 상품별로 상이

### 8.4 시장 전체 서킷브레이커 (Market-wide Circuit Breaker / Sidecar)

- **KOSPI200선물 사이드카(Sidecar):** 최근월물 선물가격이 전일 결제가격 대비 ±5% 도달 후 1분간 유지되고, 이론가 대비 ±3% 이상 괴리가 지속될 경우 발동
- 발동 시 전 파생상품 계약 5분간 거래 중단
- **3단계 구조:** 5% → 10% → 20%
- 각 단계는 당일 1회에 한해 발동 가능

### 8.5 사전 리스크 통제 (Pre-trade Risk Controls)

- 회원별 최대 주문 수량 제한
- 실시간 포지션 추적 기반 일중 증거금 모니터링
- 실시간 포지션 한도 점검
- 회원사 대상 킬스위치(Kill Switch) 기능 운영
- 주문 수락 전 자동화된 리스크 매개변수 점검
